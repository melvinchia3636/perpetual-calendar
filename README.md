# 全民万年历 (perpetual-calendar)

Expo mobile app plus a fully offline Chinese almanac engine.

## Structure

```
.
├── app.json                Expo config
├── metro.config.js         NativeWind transformer
├── postcss.config.mjs      Tailwind 4 PostCSS plugin
├── nativewind-env.d.ts     generated by react-native-css
├── assets/                 icons & splash
└── src/
    ├── App.tsx             app screen
    ├── index.ts            Expo entry (registerRootComponent)
    ├── global.css          Tailwind 4 entry
    ├── css.d.ts            declares *.css imports
    └── lib/                offline almanac engine (see src/lib/README.md)
        ├── core/
        ├── expo/
        ├── types/
        └── index.ts        Bun CLI
```

## Run (development build)

Expo Go is **not** used. The app runs as a development build so the native
runtime matches React Native 0.88 — this also avoids the `expo-asset`
`getAssetByID` error seen in Expo Go.

```bash
bun install

bun run android      # prebuild + build + start (Android SDK)
bun run start        # Metro for an already-installed dev build
bun run start:clear  # same, with a cleared Metro cache
bun run prebuild     # regenerate android/
bun run typecheck
```

`android/` is generated by Expo prebuild and is gitignored; the config lives in
`app.json`.

### NativeWind `AssetRegistry` patch

NativeWind 5 RC aliases `react-native` to its `react-native-css/components`
shim, which did not export `AssetRegistry`. That broke `expo-asset` with
`Cannot read property 'getAssetByID' of undefined` (fonts and icons).

`scripts/patch-react-native-css.mjs` runs on `postinstall` and adds the missing
getter. Remove it once `react-native-css` ships the fix. After installing
dependencies, restart Metro with `bun run start:clear`.

## Almanac engine

`src/lib` is a dependency-light, fully offline engine built on
`lunar-javascript` 1.7.7. It returns plain JSON and never touches the network.

```ts
import { getDay, findGoodDays } from './src/lib/core';

const details = getDay('2026-10-30');
const good = findGoodDays('2026-10', '嫁娶', { scope: 'both' });
```

CLI (Bun):

```bash
bun run almanac 2026-10-30
bun run almanac 2026-10 --yi 嫁娶
bun run almanac 2026-10 --yi 嫁娶 --hour
bun run almanac 2026-10 --ji 开市 --both
```

Full engine docs: [`src/lib/README.md`](src/lib/README.md).

The 宜/忌 rule is **sect 1** (on a 节 day the whole day belongs to the new
month). This differs from the original qmrl888 site on the 12 节 days by
design.

## Setup notes

- `global.css` uses Tailwind 4's layered imports plus `nativewind/theme`.
- `metro.config.js` wraps the Expo config with `withNativewind`.
- `postcss.config.mjs` registers `@tailwindcss/postcss`.
- `nativewind-env.d.ts` is generated by `react-native-css` (committed).
- `src/css.d.ts` declares `*.css` side-effect imports for TypeScript.
- `src/components/AppText.tsx` applies the Noto Sans SC family and switches
  between the regular and bold faces based on `font-bold` / `font-semibold`.
- `src/App.tsx` imports `./global.css` once, then wraps the app in
  `SafeAreaProvider` + `PaperProvider`.
- Paper icons come from `@expo/vector-icons` (MaterialCommunityIcons).
- `src/lib/index.ts` is the Bun CLI and is excluded from the app `tsconfig`
  because it uses the `Bun` global.
